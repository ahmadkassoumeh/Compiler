# البند الأول: التعريف بالتقنيات المستخدمة

هذا النص مسودة أولية قابلة للإضافة إلى تقرير المشروع، ومكتوب بحسب التقنيات المذكورة في ملف التكليف.

## 1. لغة Java والبنية البرمجية المستخدمة

Java لغة برمجة عامة الغرض، كائنية التوجه، وتعمل على بيئات تشغيل متعددة من خلال Java Virtual Machine (JVM). يعتمد المشروع على Java لكتابة منطق التطبيق وخدمات التحليل التي تستدعي المحللات المولّدة بواسطة ANTLR.

أهم المفاهيم البرمجية المستخدمة في بنية المشروع:

- **Class:** قالب يعرّف البيانات والعمليات التي تخص جزءاً من النظام.
- **Object:** نسخة من الصنف تُستخدم أثناء تشغيل البرنامج.
- **Method:** عملية تنفّذ مهمة محددة.
- **Package:** وسيلة لتنظيم الأصناف ضمن مجموعات منطقية.
- **Interface / Inheritance / Polymorphism:** مفاهيم من البرمجة كائنية التوجه تساعد على فصل المسؤوليات وتوسعة التصميم. ستظهر أهميتها بصورة أوضح عند بناء عقد AST والوراثة بينها في بند لاحق.
- **Maven:** أداة لإدارة بناء المشروع واعتمادياته، مثل مكتبات Spring Boot وANTLR.

في هذا المشروع، نقطة تشغيل التطبيق هي `CompilerWebAnalyzerApplication`، بينما وُزّعت مسؤوليات استقبال الطلبات والتحليل ونماذج النتائج على أصناف منفصلة.

## 2. إطار العمل Spring Boot

Spring Boot إطار عمل مبني على منظومة Spring، يسهّل إنشاء تطبيقات Java ويقلّل الحاجة إلى الإعداد اليدوي المتكرر. يوفر إعداداً تلقائياً ومكونات جاهزة لتشغيل تطبيق ويب، كما يمكن تشغيل التطبيق باستخدام خادم ويب مضمّن.

المكونات المستخدمة في النسخة الأولية من المشروع:

- **`@SpringBootApplication`:** تهيئة تطبيق Spring Boot ونقطة تشغيله.
- **Controller:** يستقبل طلبات HTTP من المتصفح ويحدد الاستجابة المناسبة. يستخدم المشروع `@Controller` مع `@GetMapping` لعرض الصفحة و`@PostMapping` لاستقبال النص المراد تحليله.
- **Service:** يحتوي منطق التحليل، ويستدعي Lexer وParser بدلاً من وضع هذا المنطق داخل Controller.
- **Model:** يحمل البيانات التي يريد Controller إرسالها إلى صفحة العرض، مثل قائمة الرموز وشجرة Parse Tree والأخطاء.
- **Dependency Injection:** يوفّر Spring الكائنات المطلوبة للأصناف، مثل حقن `AnalyzerService` داخل Controller.
- **Maven Dependencies:** يضيف المشروع اعتماديات الويب وThymeleaf وANTLR من خلال `pom.xml`.

## 3. محرك القوالب Thymeleaf وSyntax الخاص به

Thymeleaf محرك قوالب يعمل من جهة الخادم، ويُستخدم مع تطبيقات Java وSpring لدمج البيانات مع صفحات HTML قبل إرسالها إلى المتصفح. يعتمد على خصائص (Attributes) تبدأ غالباً بالبادئة `th:`.

أمثلة على التراكيب الشائعة:

- **`th:text`:** وضع قيمة نصية ضمن عنصر HTML.
- **`th:if` و`th:unless`:** إظهار عنصر أو إخفاؤه بحسب شرط.
- **`th:each`:** تكرار عنصر على مجموعة بيانات.
- **`th:href` و`th:src`:** إنشاء روابط أو مسارات موارد ديناميكية.
- **`th:action`:** تحديد عنوان إرسال النموذج.
- **`th:object` و`th:field`:** ربط حقول النموذج بكائن بيانات.
- **`${...}`:** تعبير للوصول إلى متغير أو خاصية ضمن السياق.

مثال:

```html
<div th:if="${product != null}">
    <h2 th:text="${product.name}">Product name</h2>
</div>
```

في Grammar الحالية، يتعرف Lexer على اسم الخاصية التي تبدأ بـ `th:` بوصفها `TH_ATTRIBUTE`، بينما تُقرأ قيمة الخاصية النصية كقيمة Attribute. تحليل تفاصيل تعبيرات Thymeleaf داخل `${...}` هو توسعة لاحقة، وليس جزءاً مكتملاً من Grammar الحالية.

## 4. لغة HTML وبنيتها الأساسية

HTML لغة توصيف تُستخدم لبناء بنية صفحات الويب. تتكون الصفحة عادةً من عناصر (Elements)، ويتكون العنصر الشائع من وسم بداية وخصائص ومحتوى ووسم نهاية.

مثال:

```html
<h1 class="title">Hello</h1>
```

يتضمن المثال:

- وسم البداية: `<h1>`.
- اسم العنصر: `h1`.
- خاصية: `class="title"`.
- محتوى نصي: `Hello`.
- وسم النهاية: `</h1>`.

تُكتب العناصر داخل بعضها، لذلك يمكن تمثيل بنية HTML بشجرة. توجد أيضاً عناصر فارغة (Void Elements) مثل `img` و`br` لا تحتاج إلى وسم إغلاق وفق بنية HTML المعتادة.

## 5. لغة CSS وبنيتها الأساسية

CSS لغة تنسيق تتحكم بمظهر عناصر صفحة الويب. القاعدة الأساسية تتكون من محدد (Selector) ثم كتلة تحتوي تصريحاً واحداً أو أكثر (Declarations). ويتكون التصريح عادةً من خاصية وقيمة.

مثال:

```css
.card {
    color: #333;
    margin: 12px;
}
```

- **Selector:** `.card` ويحدد العناصر المستهدفة.
- **Declaration Block:** ما بين `{` و`}`.
- **Property:** مثل `color` و`margin`.
- **Value:** مثل `#333` و`12px`.

قد تتضمن CSS أيضاً محددات مركبة، ومحددات شبهية مثل `:hover`، وقواعد تبدأ بـ `@` مثل `@media`.

## علاقة التقنيات داخل المشروع

يُكتب منطق التطبيق بلغة Java، ويستقبل Spring Boot طلب المستخدم ويعالج المسارات، ثم يستدعي خدمة التحليل. تستخدم الخدمة محللات ANTLR لتحليل النصوص المدخلة، وتُعرض نتائج التحليل لاحقاً عبر صفحات Thymeleaf المبنية بلغة HTML والمنسقة باستخدام CSS.
